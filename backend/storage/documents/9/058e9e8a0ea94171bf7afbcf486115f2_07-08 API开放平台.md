# Nebula 开放平台（API 开放平台）

| 版本 | 适用对象 |
| --- | --- |
| V1.0 | 开放平台接入方 / 集成开发者 |

> API 开放平台用于外部系统与 Nebula 各产品（OA/CRM/Knowledge/IoT/AI）的标准化接口接入。

---

## 一、接入认证

- **AppId + AppSecret** 申请：向平台注册应用，获取接入凭证。
- **签名鉴权**：请求带签名（HMAC-SHA256）+ 时间戳，服务端校验签名与时效。
- Token 方式：认证后获取访问 Token，请求头携带。

> 详细签名与 Token 规范见《06-08 接口安全规范》。

---

## 二、接口列表与说明

- 提供 OA（审批/待办）、CRM（客户/机会/合同）、Knowledge（知识检索）、IoT（数据上报）等接口。
- 每个接口含：方法、路径、参数、返回结构、调用示例。
- 接口遵循《06-04 REST接口规范》。

---

## 三、鉴权与安全

- 分环境（测试/生产）配置凭证，生产凭证严格保密。
- 敏感数据返回脱敏，传输走 HTTPS。
- 请求带幂等键与时间戳，防重放。

---

## 四、限流与配额

- 各应用有调用配额/频率限制（QPS）。
- 超限返回限流错误码，可按需申请提升配额。

---

## 五、错误码

| 错误码 | 含义 |
| --- | --- |
| 401 | 未认证/凭证错误 |
| 403 | 无权限 |
| 404 | 接口不存在 |
| 429 | 超限流 |
| 5xx | 服务端异常 |

---

## 六、调试沙箱

- 提供测试环境与沙箱，便于接入调试。
- 沙箱数据与生产隔离，不含真实敏感数据。
