# Nebula SDK 开发文档

| 版本 | 适用对象 |
| --- | --- |
| V1.0 | 集成开发者 |

> SDK 封装 Nebula 各产品 API，帮助开发者在自有系统中快速接入。

---

## 一、SDK 支持语言

- 提供 Java、Node.js、Python 等主流语言 SDK（以发布为准）。
- 通过包管理安装并从公司私有源/平台获取。

---

## 二、安装 / 引入

```bash
# Java (Maven)
# 在 pom.xml 引入 nebula-sdk 依赖
# Node
npm install @nebula/sdk
# Python
pip install nebula-sdk
```

- 安装前请先在开放平台获取 AppId / AppSecret。

---

## 三、初始化

```java
NebulaClient client = new NebulaClient(
    appId, appSecret, "https://open.baidu.com/v1", env);
```

- 传入凭证与服务地址，SDK 自动处理签名与 Token。

---

## 四、核心接口示例

```java
// 查询客户列表（CRM）示例
PagedResult<Customer> result = client.crm().queryCustomer(page, size);

// 知识检索（Knowledge）示例
List<Hit> hits = client.knowledge().search("如何申请报销", topK);
```

- 各功能模块（crm/oa/knowledge/iot/ai）提供对应方法，返回统一结构。

---

## 五、事件回调

- 支持订阅回调事件（如审批完成、设备告警），SDK 提供回调处理器。
- 注册回调地址并校验签名，防止伪造。

---

## 六、版本发布记录

- SDK 版本与后端 API 版本对应，升级前查看兼容性说明。
- 破坏性变更会升主版本并同步文档。
