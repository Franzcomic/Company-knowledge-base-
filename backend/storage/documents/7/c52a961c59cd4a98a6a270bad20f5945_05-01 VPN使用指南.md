## 一、VPN 简介

公司使用 VPN（虚拟专用网络）实现员工在外网环境安全访问公司内网资源（GitLab、OA、内部系统等）。**外网访问公司内网前须先连接 VPN。**

## 二、VPN 安装

### 2.1 支持系统
- Windows 10/11
- macOS
- 部分支持移动端（Android/iOS）

### 2.2 安装步骤（以 Windows 为例）

1. 联系 IT 获取 VPN 客户端安装包与安装说明。
2. 双击安装包，按提示完成安装（默认配置）。
3. 安装完成后在系统托盘/任务栏找到 VPN 客户端图标。

> 安装过程如需管理员权限，请联系 IT 协助。

## 三、VPN 登录

1. 打开 VPN 客户端，点击「连接」。
2. 输入**域账号 + 密码**（与公司电脑登录账号一致）登录。
3. 连接成功后显示「已连接」，即可访问内网资源。
4. 使用完毕建议断开连接以保障安全。

## 四、VPN 常见错误

| 报错 / 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| 连接超时无法建立 | 客户端版本过低/网络异常 | 升级客户端、重启电脑、检查网络 |
| 认证失败（账号/密码错误） | 账号停用或密码错误 | 核对账号、重置密码 |
| 连接后无法访问内网 | 未正常登录或网络分配异常 | 重新连接、联系 IT |
| 提示证书/授权问题 | 客户端或证书异常 | 重装客户端、联系 IT |

## 五、VPN 重置密码

1. 在公司自助服务平台或 OA 自助重置密码。
2. 若无法自助重置，请联系 IT 支持（电话/工单）。
3. 密码重置后，VPN 使用新密码重新登录。

## 六、联系 IT 支持

- 遇到无法解决的问题，通过 OA 提交 IT 工单或拨打 IT 技术支持热线。
