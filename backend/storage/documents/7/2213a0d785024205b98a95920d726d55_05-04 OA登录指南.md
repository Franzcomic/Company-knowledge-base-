# 星云智联科技有限公司 OA 登录指南

| 版本 | 维护部门 |
| --- | --- |
| V1.0 | 运维部 / 信息管理中心 |

---

## 一、访问地址

- OA 办公系统网页地址由 IT 统一发布（局域网/外网 VPN 均支持）。
- 外网访问时请先连接 VPN（见《05-01 VPN使用指南》）。

## 二、浏览器要求

- 推荐使用 Chrome / Edge 最新版本。
- 使用前开启 Cookies，必要时允许弹出窗口。

## 三、登录方式

1. 打开 OA 地址，进入登录页。
2. 输入**工号/账号 + 密码**登录。
3. 首次登录建议修改初始密码。

## 四、找回 / 重置密码

- 忘记密码时：
  1. 点击登录页「忘记密码 / 找回密码」。
  2. 按要求验证身份（手机验证码/邮箱验证）。
  3. 重置为新密码后重新登录。
- 无法自助重置的联系 IT 支持。

## 五、常见登录异常

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 确认网络与 VPN，更换浏览器 |
| 提示账号或密码错误 | 核对账号、重置密码 |
| 提示账号锁定 | 联系 IT 解锁 |
| 登录成功后页面空白 | 清理浏览器缓存，重启浏览器 |
