## 一、环境概览

研发环境核心组件：**JDK、Maven、Node、Git、IDEA**（及其他按项目需要的工具）。以下版本为研发基线，具体以项目需求为准。

| 组件 | 推荐版本 |
| --- | --- |
| JDK | 8 或 11 / 17（按项目） |
| Maven | 3.6 以上 |
| Node.js | 16 以上 |
| Git | 最新稳定版 |
| IntelliJ IDEA | Community/Ultimate 最新版 |

---

## 二、JDK 安装

1. 下载 JDK 安装包（从官方/Oracle、OpenJDK 或公司私有源）。
2. 安装时记住安装路径（如 `C:\Program Files\Java\jdk-17`）。
3. 配置环境变量：
   - `JAVA_HOME` → JDK 安装路径
   - `Path` 追加 `%JAVA_HOME%\bin`
4. 验证：命令行 `java -version`。

## 三、Maven 安装

1. 解压 Maven 到指定目录（如 `D:\tools\apache-maven`）。
2. 配置环境变量：
   - `MAVEN_HOME` → Maven 目录
   - `Path` 追加 `%MAVEN_HOME%\bin`
3. 配置 `settings.xml` 中的公司私有仓库镜像（按团队共享说明）。
4. 验证：`mvn -v`。

## 四、Node 安装

1. 下载 Node LTS 安装包并安装。
2. 通过命令行校验：`node -v`、`npm -v`。
3. 按项目使用 npm/yarn/pnpm，必要时配置镜像源加速。

## 五、Git 安装

1. 下载并安装 Git for Windows 官方安装包。
2. 安装后配置用户信息：
   - `git config --global user.name "yourname"`
   - `git config --global user.email "yourname@xxxx.com"`
3. 配置 SSH Key（见《05-05 GitLab使用指南》），便于连接 GitLab。
4. 验证：`git --version`。

## 六、IDEA 安装

1. 下载 IntelliJ IDEA 安装包并安装。
2. 首次启动配置 JDK（Project SDK 选择 JDK 版本）。
3. 配置 Maven（Settings → Build Tools → Maven，指定 maven home 与 settings.xml）。
4. 安装常用插件（Lombok、MyBatisX、Spring 等，按团队规范）。

## 七、常见坑点

| 问题 | 处理 |
| --- | --- |
| `java` 不是内部命令 | 检查 JAVA_HOME 与 Path 是否正确 |
| mvn 依赖下载失败 | 检查 settings.xml 镜像与网络，必要时连 VPN |
| npm 安装慢/失败 | 配置镜像源、清理缓存 |
| IDEA 无法编译 | 检查 SDK、Maven settings 与项目 JDK 配置 |
