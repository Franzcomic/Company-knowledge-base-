# 星云智联科技有限公司 项目开发流程

| 版本 | 适用 |
| --- | --- |
| V1.0 | 研发中心 · 项目团队 |

---

## 一、开发流程总览

```text
需求收集 → 需求评审 → 设计 → 评审 → 开发 → 测试 → 上线 → 复盘
```

---

## 二、需求阶段

### 2.1 需求收集与评审
- 业务方提出需求，产品部整理需求文档（PRD）。
- 组织需求评审会，确认业务规则、验收标准。
- 评审通过后形成需求基线，变更走变更流程。

### 2.2 产出物
- 需求文档、原型图、验收标准（DoD）。

---

## 三、设计阶段

- 输出**技术方案 / 系统设计**：架构、数据库设计（见《06-05 数据库设计规范》）、接口设计（见《06-04 REST接口规范》）。
- 组织设计评审，评估风险与工作量。

### 产出物
- 系统设计说明书、接口文档、数据库设计文档、ER 图。

---

## 四、开发阶段

- 按迭代/任务拆分，使用 Git 分支开发（见《06-02 Git使用规范》）。
- 遵循编码规范（见《06-01 Java编码规范》）。
- 完成后发起 Code Review（见《06-09 Code Review规范》）。

---

## 五、测试阶段

- 测试部编写测试计划与用例，进行功能、回归、性能、安全测试。
- 提交缺陷走缺陷跟踪链路，开发修复后回归验证。
- 达到上线标准输出**测试报告**。

---

## 六、上线阶段

- 制定上线计划与回滚方案，经审批后部署。
- 发布走发布窗口，灰度/蓝绿等按风险选择。
- 上线后监控运行情况，问题快速回滚或修复。

---

## 七、复盘与文档沉淀

- 上线后进行复盘，沉淀经验与改进项。
- 更新相关文档与知识库，便于后续团队查阅。
