# 星云智联科技有限公司 接口安全规范

| 版本 | 适用 |
| --- | --- |
| V1.0 | 研发中心 · 接口/平台开发 |

---

## 一、认证与授权

### 1.1 认证方式
- 默认使用 **JWT（无状态 Token）** 或服务端 Session。
- 登录后签发 Token，接口通过 Token 识别调用者身份。
- Token 设置合理有效期，支持续期/失效机制。

### 1.2 鉴权
- 每次请求校验**权限范围**（RBAC 角色/资源），防止水平越权（他人数据）。
- 禁止仅在前端做权限控制，后端必须二次校验。

---

## 二、API 认证方式（开放平台/内部系统）

| 场景 | 认证方式 |
| --- | --- |
| 内部系统 | JWT / 单点登录 Token |
| 开放平台外部调用 | **AppId + AppSecret 签名**（HMAC-SHA256） |
| 服务间调用 | mTLS 或密钥签名 |

- 签名参数包含时间戳防重放，过期请求拒绝。
- Secret 只存服务端，不落前端。

---

## 三、传输安全

- 对外接口强制 **HTTPS** 加密传输。
- 敏感信息（密码、Token）不得通过 URL 明文传递，放请求头/请求体。

---

## 四、接口限流

- 对开放接口/高频接口做**限流**（按账号、IP、业务维度）。
- 超限返回友好错误码，避免拖垮后端与数据库。

---

## 五、防重放

- 幂等键 + 时间戳/随机数校验，防止重复提交与重放攻击。

---

## 六、敏感数据脱敏

- 输出到前端/日志的敏感字段（手机号、身份证、卡号）进行**脱敏**。
- 示例：`138****5678`。
- 密码一律单向加密存储（BCrypt 等），禁止明文/可逆加密。

---

## 七、参数与权限校验

- 入参白名单校验，长度、类型、枚举范围限制。
- 越权检查：资源归属用当前登录用户校验，杜绝未授权访问。
