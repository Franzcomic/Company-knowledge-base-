## 一、办公 WiFi 信息

| 项目 | 说明 |
| --- | --- |
| 办公网络名称 | `Nebula-Office`（示例） |
| 加密方式 | WPA2/WPA3 |

## 二、连接步骤

1. 打开设备 WiFi，选择办公网络名称。
2. 输入工号/域账号与密码认证（或输入统一连接密钥）。
3. 认证通过后自动连上，即可访问公司网络。
4. 部分设备可勾选「自动加入」，下次自动连接。

## 三、账号认证说明

- 员工使用**公司域账号/工号**登录办公 WiFi。
- 首次使用若提示需要登记，联系 IT 完成账号绑定。

## 四、访客网络

- 访客可通过行政部申请访客账号，使用独立的访客 WiFi 网络。

## 五、常见连接问题

| 问题 | 处理 |
| --- | --- |
| 找不到办公 WiFi | 确认区域网络覆盖，靠近信号源 |
| 认证失败 | 核对工号/密码，重置域账号密码 |
| 连接成功但无网 | 检查是否需连 VPN（访问内网），或联系 IT |
| 频繁掉线 | 更换连接方式、联系 IT 排查 |
