## 一、企业邮箱账号

- 企业邮箱账号为 `姓名拼音@xxxx.com`（按公司规范分配）。
- 邮箱密码与域账号同步，修改密码请通过自助平台或 IT 支持。

## 二、网页端登录

1. 浏览器访问企业邮箱网页地址。
2. 输入邮箱地址与密码登录。
3. 建议勾选「记住我」前的安全设置按需选择，并定期修改密码。

## 三、客户端配置（Outlook / 手机）

### 3.1 关键服务器信息（以管理员提供为准）

| 协议 | 服务器地址 | 端口 / 加密 |
| --- | --- | --- |
| 收信 IMAP | xxx.xxxx.com | 993 (SSL) |
| 发信 SMTP | xxx.xxxx.com | 465 (SSL) |

### 3.2 Outlook 配置步骤
1. 新建账户「手动配置或更多服务器类型」。
2. 选择 IMAP/POP，填写邮箱、用户名、密码与服务器地址。
3. 加密方式选择 SSL/TLS，点击「测试」通过后完成。

### 3.3 手机端配置
- Android/iOS 邮件应用或企业邮箱 App：填写邮箱、密码与服务器配置即可。
- 为保证同步可用，建议使用官方/统一邮件客户端。

## 四、密码重置

- 忘记密码时：
  1. 通过公司自助服务平台或 OA 自助重置。
  2. 无法自助的，联系 IT 支持验证身份后重置。

## 五、常见配置问题

| 问题 | 处理 |
| --- | --- |
| 测试连接失败 | 检查服务器地址、端口、加密方式 |
| 一直提示密码错误 | 确认密码是否改动，重置后再试 |
| 收不到新邮件 | 检查服务器设置与客户端同步间隔 |
| 发送被退回 | 检查收件人地址与发信权限，便联系 IT |
