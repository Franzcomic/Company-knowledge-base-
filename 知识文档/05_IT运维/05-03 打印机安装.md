## 一、打印机环境

- 办公区提供共享网络打印机/复印一体机，员工可通过公司网络添加使用。

## 二、驱动安装

### 2.1 获取驱动
- 驱动由 IT 统一提供，或从打印机厂商官网下载对应型号驱动。

### 2.2 安装步骤（Windows）
1. 从 IT 提供的路径运行驱动安装程序。
2. 选择打印机型号并完成安装。
3. 安装完成后在「设置 → 打印机」中确认已添加。

> 需要管理员权限时可联系 IT 协助安装。

## 三、添加共享 / 网络打印机

1. 打开「控制面板 → 设备和打印机 → 添加打印机」。
2. 选择网络打印机，输入打印机 IP 或选择共享队列名称。
3. 选择对应驱动，完成添加并设置为默认打印机（可选）。

## 四、打印测试

- 添加后打印测试页验证是否正常。
- 若驱动匹配错误，重新选择正确型号驱动。

## 五、无法连接打印机排查

| 现象 | 排查步骤 |
| --- | --- |
| 找不到打印机 | 确认打印机 IP/名称正确，网络是否为办公网 |
| 驱动不匹配 | 安装对应型号的官方驱动 |
| 一直显示离线 | 检查打印机电源/网络，联系 IT |
| 提交任务无响应 | 重启打印服务或电脑，清除打印队列 |

**说明：办公电脑无法连接打印机时，优先确认是否已连接公司网络并正确安装驱动，仍无法解决则提交 IT 工单。**
