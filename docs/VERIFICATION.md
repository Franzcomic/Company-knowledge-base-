## 本轮改动

- Java 21、Maven Wrapper、环境变量模板、独立 Compose、CI 与启动脚本。
- 知识库和文档资源级授权，上传文件名路径校验。
- JWT 校验后重新加载当前角色、部门和账号状态。
- 生成前复核来源权限及 READY 状态；权限更新在事务提交后触发重新入库。
- 空回答记为拒答，移除重复嵌入调用，默认关闭调试探针。
- 常见问题入口、防重复发送、模型等待时间及管理按钮权限。
- 替换购物/支付等旧图，补齐架构、用例、活动、类、时序、权限和 ER 图，校正接口和字段。

## 完整验收方法

按 README 启动服务并导入样例，分别用员工、部门管理员和系统管理员执行文档上传、状态查询、问答、来源预览、历史、评价、权限收紧和统计。使用 `知识文档/Test/知识库测试问题集.json` 人工核对答案及来源，另存真实结果，不能用页面原型替代模型效果评估。
