## 一、技术选型（复用已定选型 + 现成模板）

### 1.1 技术栈
| 用途 | 选型 | 说明 |
|---|---|---|
| 框架 / 构建 | **Vue 3 + Vite + TypeScript** | 已定，Vite 加速开发/构建 |
| 组件库 | **Element Plus** | 已定，直接沿用（与 vue-pure-admin 内建一致） |
| 状态管理 | **Pinia** | 已定，管理登录态 / 用户信息 / 会话上下文 |
| 路由 | **Vue Router** | 已定，配合权限守卫做登录拦截与角色路由 |
| HTTP | **Axios** | 封装拦截器：JWT 注入 + `{code,msg,data}` 解包 + 401 跳登录 |
| 图表（P2） | **ECharts** | 统计看板卡片/趋势/排名/命中率图 |
| 上传 | Element Plus `<el-upload>` | 自带拖拽 + 进度，接文档上传接口 |

### 1.2 模板方案（推荐第三人称成熟，不用从零搭）
| 方案 | 选择 |
|---|---|
| **vue-pure-admin**（Vite + Vue3 + Pinia + Element Plus） | ★ 首选。轻量、与已定技术栈一致、RBAC 动态路由开箱即用、易改成个人/双端结构 |
| vue-vben-admin（新版） | 备选。功能更全但更重，组件库走向 AntD/shadcn，与本项目已定 Element Plus 不一致，改造成本高 |
| 自研骨架 | 仅在需要完全掌控结构时选用，成本最高 |

**推荐结论**：以 **vue-pure-admin** 为基座，删除自带业务示例，保留登录、权限、布局、Axios 封装等能力，按本计划填充本项目页面。

> 提示：知识库级数据权限不在前端做，由后端 `/api/rag/retrieve` 的 Metadata Filter 控制；前端仅做"可见/禁用"维度，避免越权信息暴露。

## 二、前端项目结构与模块对应

```
src/
├─ api/                  # 按模块封装接口
│   ├─ auth.ts           # 模块① 登录/登出/me
│   ├─ user.ts           # 模块①(P1) 用户/角色/部门
│   ├─ kb.ts             # 模块② 知识库
│   ├─ document.ts       # 模块② 文档上传/列表/详情/chunks
│   ├─ conversation.ts   # 模块⑥⑦ 会话 CRUD / 历史消息
│   ├─ rag.ts            # 模块④⑤ 检索 / chat（内部契约）
│   └─ stats.ts          # 模块⑧ 统计
├─ stores/               # Pinia
│   └─ user.ts           # 登录态、当前用户与角色、token
├─ router/               # 路由表 + 权限守卫（P0 认证，P1 角色路由）
├─ layout/               # 布局（后台管理框架 + 顶部用户/登出）
├─ views/
│   ├─ auth/             # 登录页（模块① P0）
│   ├─ chat/             # 问答会话主界面（模块⑤⑥⑦，员工端核心）
│   ├─ kb/               # 知识库列表 + 文档管理与上传（模块②）
│   └─ admin/            # 用户/角色/部门管理（P1）· 统计看板（P2 模块⑧）
├─ components/
│   ├─ ChatMessage.vue   # 消息气泡（文本 + 来源引用 + 相似度 + 赞/踩）
│   ├─ SourceCard.vue    # 来源片段卡片（可点击跳转文档预览）
│   └─ ConversationList.vue  # 会话侧边栏（新建/切换/删除）
└─ utils/request.ts      # Axios 拦截器
```

**模块 → 前端页面对应**
| 模块 | 前端页面/组件 |
|---|---|
| ① 用户与权限 | 登录页、个人资料；P1：用户/角色/部门管理页 |
| ② 文档与知识库 | 知识库列表、文档列表、上传（拖拽+进度）、删除确认；P1：文档详情 chunk 预览、重向量化、权限设置 |
| ③ 文档处理管道 | 无独立页面，由上传与文档状态页驱动 |
| ④ RAG 检索 | 无独立页，在问答会话中展示检索片段与相似度 |
| ⑤ 大模型回答 | 问答会话中渲染答案 + 来源引用 |
| ⑥ 智能问答会话 | **问答主界面**：ChatMessage / 输入框 / 多轮 / 会话侧边栏；P1：评价 |
| ⑦ 历史记录 | 会话侧边栏、历史消息查看、续聊 |
| ⑧ 统计与分析 | 管理员统计看板（ECharts），P2 |

## 四、组件复用与交付约定

- **问答相关组件（ChatMessage / SourceCard / ConversationList）是本项目核心自研件**，模板无现成替代，建议独立成目录并写最小注释说明数据结构，避免与模板组件耦合。

- 统一返回结构 `{ code, msg, data }` 在 Axios 拦截器中统一处理，页面无需关心 code。
- 样式沿用 Element Plus 主题变量，临时样式不进全局（优先 scoped）。
