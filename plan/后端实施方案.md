### 硬骨头 2 · Milvus Metadata Filter 语法
**问题**：`department in [dept, null]` 依赖 `null` 与 `<=` 字符串比较，Milvus 的 `null` 语义与 SQL 不同，很可能不按预期，且要返工重建 collection。
**落地决策**：
- **（2026-09-17 实测修订）不建显式标量字段**：Spring AI 2.0 `MilvusVectorStore` 只支持单个 `metadata` JSON 字段，无法映射多标量列；改为 **JSON 子字段方案**：`department_id`/`permission_level`/`category`/`source` 全部存入 `metadata` JSON，过滤表达式用 `metadata["department_id"] in [0, <userDept>] && metadata["permission_level"] <= <userLevel>`（Spring AI 转换器实测支持 ` && / || / == / != / <= / >= / in / not in`，键自动包装为 `metadata["..."]`）。
- **JSON 子字段索引**（性能）经 `CreateIndexReq` 创建：`fieldName="metadata"` + `extraParams["json_path"]="metadata[\"department_id\"]"` + `json_cast_type=DOUBLE`、`AUTOINDEX`（注意：**路径不能放 fieldName**，否则报 `cannot create index on non-exist field`）。
- **不用 `null` 表示"全司"**：全司记录 `department_id = 0`，过滤写 `department_id in [0, <userDept>]`。
- **权限级别用整数排序**：`PUBLIC=0, DEPT=1, CONFIDENTIAL=2`，过滤用数值比较 `permission_level <= <userLevel>`，规避字符串比较不确定性。
- **阶段 2 建集后立刻做独立 filter 冒烟测试**（样例数据验证表达式结果），不等到阶段 4 集成期；否则失败需重建 collection 并重新 embedding 全部文档。

### 硬骨头 3 · 异步入库状态一致性与前端刷新
**问题**：`POST /api/kb/{kbId}/documents` 立即返回 `status=PARSING`，前后端未约定"何时变 READY"，前端无法刷新状态。
**落地决策（新增契约）**：
- 前端上传后**轮询 `GET /api/documents/{id}`，每 2~3 秒，status 非 `PARSING` 即停**。
- 后端另提供批量查询 `GET /api/documents?status=PARSING`（可选）供列表页一次刷多文档状态。
- 轮询超时（如 3 分钟）前端给出"处理超时/失败"提示；后端 `@Retryable` + `FAILED` 兜底（见 §七阶段 2）。

## 三、数据库设计（MySQL 8，字段级 DDL）

MyBatis-Plus 约定：主键自增 `id BIGINT`；统一含 `created_at/updated_at DATETIME`；表名蛇形、字段蛇形；实体名驼峰对齐。DDL 落位 `backend/src/main/resources/db/schema.sql`，含种子数据。

### 3.1 user
```sql
create table user (
  id            bigint auto_increment primary key,
  username      varchar(64)  not null,
  password_hash varchar(128) not null,          -- BCrypt
  real_name     varchar(64)  null,
  email         varchar(128) null,
  phone         varchar(32)  null,
  department_id bigint       null,
  role_id       bigint       not null,
  status        tinyint      not null default 1, -- 1正常 0停用

  updated_at    datetime     not null default current_timestamp on update current_timestamp,
  unique key uk_username (username),
  key idx_department (department_id), key idx_role (role_id)
);
```

## 四、统一返回与异常

```java
// 统一返回体
public record Result<T>(int code, String msg, T data) {
  public static <T> Result<T> ok(T data) { return new Result<>(200, "success", data); }
  public static <T> Result<T> fail(ResultCode c) { ... } // 401/400/404/500
}
```
- `ResultCode`：`OK(200)`、`UNAUTHORIZED(401)`、`BAD_REQUEST(400)`、`NOT_FOUND(404)`、`ERROR(500)`。
- `GlobalExceptionHandler`：`BusinessException`、`@Valid` 校验、`AccessDeniedException`、兜底 `Exception` 统一转 `Result`。
- **前端匹配**：`code===200` 成功取 `data`；`code===401` 前端跳登录。

## 五、Spring AI 组件映射与 RAG 参数

```yaml
spring:
  servlet.multipart:
    max-file-size: 10MB            # 与前端 .env VITE_UPLOAD_MAX_MB=10 一致
    max-request-size: 10MB
  ai:
    model: { chat: openai, embedding: openai }
    openai:
      base-url: http://localhost:1234/v1
      api-key: lm-studio            # 任意占位即可，LM Studio 本地服务不校验真实 key
      chat:   { options: { model: google/gemma-4-e4b, temperature: 0.2 } }
      embedding: { options: { model: text-embedding-bge-m3 } }   # 实测加载 id
    vectorstore:
      milvus:
        client: { host: localhost, port: 19530, databaseName: default }
        initialize-schema: true
        embedding-dimension: 1024
rag:
  chunk-size: 500
  chunk-overlap: 100
  top-k: 10
  rerank-top: 3
  similarity-threshold: 0.6
  collection: knowledge_chunks    # 度量 COSINE
```
Prompt 模板与兜底文案沿用《项目实施计划.md》§4.5。

**Milvus collection `knowledge_chunks` 权限元数据（2026-09-17 实测修订为 JSON 子字段方案，见 §〇 硬骨头 2）**
- 集合 schema 与 Spring AI 2.0 `MilvusVectorStore` 默认一致：`doc_id VarChar(64) PK / content VarChar(65535) / metadata JSON / embedding FloatVector(1024)`，度量 COSINE，主向量索引 AUTOINDEX。
- 权限过滤元数据全部存入 `metadata` JSON 子字段（无 null 语义）：
  - `department_id` int（全司=0）
  - `permission_level` int（PUBLIC=0 / DEPT=1 / CONFIDENTIAL=2，数值比较）
  - `category` varchar（知识库名，即分类）
  - `source` varchar（知识文档来源文件名）
  - `document_id` int（文档行 id，用于删除级联）· `title` · `chunk_index`
- 子字段索引（`idx_department_id`/`idx_permission_level`）：`fieldName=metadata` + `json_path` + `json_cast_type=DOUBLE`，`AUTOINDEX`；由 `MilvusSchemaInitializer`（ApplicationRunner）幂等创建，失败仅告警不阻断（过滤不依赖索引）。
- 删除级联：`metadata["document_id"] == {documentId}` 表达式删除。
